# 执行器行内目录迁移说明

```text
com.icbc.nbfh
├── RedisMonitorAgentApplication    启动类
├── common
│   ├── constant                   枚举和静态常量
│   ├── core                       仅预留公共报文返回实体类
│   └── exception                  公共异常
├── config                         Agent 配置和 Spring 配置
├── controller                     HTTP 入口
├── entity
│   ├── dto                        注册、心跳、采集和平台任务报文
│   ├── params                     各类原子操作参数
│   └── result                     命令和操作、健康检查结果
├── mapper                         数据库映射层预留包
├── service                        业务接口
│   ├── impl                       业务实现与本地结果存储
│   ├── client                     平台 HTTP 客户端
│   ├── collector                  Redis 指标采集
│   ├── command                    固定脚本执行
│   ├── health                     Redis、Sentinel 健康检查
│   ├── operation                  原子运维操作
│   └── task                       注册采集、心跳和补报定时任务
└── utils
    ├── AgentContext               Spring 上下文工具
    └── validate                   通用格式校验预留包
```

根包迁移为 `com.icbc.nbfh`。启动类为 `com.icbc.nbfh.RedisMonitorAgentApplication`，Maven 坐标的 groupId 同步为 `com.icbc.nbfh`，产物名称仍为 `redis-monitor-agent.jar`。

本次只调整代码归属、包引用和启动配置，不修改 HTTP 路径、JSON 字段、Token 文件格式、任务结果文件格式或 Linux 运维脚本。已有具体业务类保留原类名，归入 `service.impl`，不额外引入转发接口。

`common.core`、`mapper`、`utils.validate` 使用 package-info.java 预留。公共返回类需要遵循实际行内报文模板，不能为目录迁移擅自更改已有通信协议；执行器尚未使用关系数据库，不新增数据库依赖。
